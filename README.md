# pjsk-wallpaper

Project Sekai 卡面壁纸软件（桌面 + 锁屏，独立轮换，零网络常驻）。

界面是本机 Web 控制台：Python 后台服务 + 浏览器应用窗口。关闭页面不影响后台轮换。

## 环境要求

- Windows 10 / 11
- Python 3.10+（安装时勾选 "Add to PATH"）

## 安装（推荐：安装助手）

1. 解压源码到任意临时位置。
2. 双击 **`安装助手.bat`**（或 `pythonw installer.pyw`）。
3. 按向导选择安装目录 → 安装 → 完成时可勾选「创建快捷方式」「开机自启」「立即启动」。

安装器会复制文件到目标目录、检测并安装 Pillow 依赖，并清理旧版 Tkinter 入口。
所有运行数据（图库、缓存、配置）都存放在安装目录内，**升级不会清空或移动它们**。

## 手动安装（备选）

```
pip install -r requirements.txt
pythonw launcher.pyw
```

## 目录结构

```
pjsk-wallpaper\
├── installer.pyw        安装助手（向导式：选目录 → 复制文件 → 装依赖 → 快捷方式）
├── 安装助手.bat          安装助手引导器（未装 Python 时给出提示）
├── launcher.pyw         启动器（无控制台）：单实例 + 后台运行时 + HTTP 服务 + 托盘 + 打开界面
├── server.py            本机 HTTP API + 静态资源（仅绑定 127.0.0.1）
├── runtime.py           运行时：轮换/更新调度、配置快照、任务状态（不依赖 UI）
├── app/                 Web UI 静态资源（index.html / styles.css / app.js / assets）
├── gallery_update.py    图库更新脚本（独立：手动或按间隔自动触发，唯一联网处）
├── core.py              核心逻辑（配置、壁纸设置 API、图库管理、缩略图、快捷方式）
├── tray.py              系统托盘（纯 ctypes Shell_NotifyIcon，无第三方依赖）
├── set_lockscreen.ps1   锁屏壁纸设置脚本（WinRT API，无需管理员）
├── start.bat            启动器（命令行入口）
├── requirements.txt     Python 依赖（Pillow）
├── icon.png / icon.ico  程序图标（首次运行自动生成）
├── config.json          配置（首次运行自动生成，见 .gitignore，不随仓库分发）
├── library/
│   ├── pjsk/            自动获取的 Project Sekai 卡面（FIFO，上限可配置）
│   └── custom/          手动添加的图片（不受上限约束）
├── cache/               数据库缓存 + 图库缩略图（运行时自动生成）
├── runtime/             端口文件、浏览器配置、界面状态（运行时自动生成）
└── logs/update.log      图库更新日志（运行时自动生成）
```

## 使用方式

1. 双击桌面快捷方式「pjsk 壁纸」启动（也可用开始菜单或 `start.bat`）。
   程序会启动后台服务并打开浏览器应用窗口（Edge/Chrome 的 `--app` 模式）。
2. **概览**：分别查看桌面/锁屏当前壁纸，启停定时轮换、设置间隔、查看上次/下次与倒计时，
   点「下一张」立即切换；「立即更新」拉取新卡面。
3. **图库**：按来源筛选（全部 / pjsk / 自定义）、搜索、分页浏览缩略图，点击看大图；
   拖放或「添加图片…」把本地图片按屏幕分辨率填充裁剪后存入 `library/custom/`。
4. **设置**：轮换间隔与启停、图库来源与 pjsk 容量上限、更新筛选（张数/稀有度/角色/组合）
   与间隔更新开关、开机自启与快捷方式。改动在后端保存成功后显示「已保存」。
5. **配置文件**：可「导出设置」把当前设置保存为 `pjsk-wallpaper-settings.json`；
   也可把配置文件**拖入**该区域或点击选择文件来导入，**同时接受本程序导出的设置文件与原始 `config.json`**。
   导入前会做格式与取值校验，非法内容整体拒绝并逐条列出原因；只影响设置，不涉及任何图片。

## 托盘与生命周期

- 关闭浏览器窗口 / 刷新 / 浏览器崩溃都**不会**停止后台轮换；托盘图标持续存在。
- 托盘图标左键 = 打开/聚焦界面；右键菜单：打开主窗口 / 桌面下一张 / 锁屏下一张 / 退出。
- 只有托盘菜单的「退出」才会结束后台服务、定时任务与更新子进程。
- 重复启动只会有**一个**后台实例：第二次启动只会打开已有实例的界面。
- 轮换仅在后台进程运行时进行（建议配合「开机自启」使用）。

## 架构说明

### 运行模型

```
浏览器 app 窗口 ── HTTP ──> 本机 Python 服务(server.py) ──> 运行时(runtime.py) ──> core / gallery_update
                                                │
                                                └── 系统托盘 / Windows 配置
```

- Python 后台进程是业务状态的唯一权威来源；Web UI 只展示状态、下发命令，不承担任何定时任务。
- 配置变更经 API 校验后**原子写盘**（不会留下截断的 JSON），调度器读取内存中的一致快照。
- 图库更新异步执行、互斥重入，状态与结果由后端记录，不阻塞界面。

### 壁纸轮换

- **桌面壁纸**：`SystemParametersInfo`（`SPI_SETDESKWALLPAPER`）设置，无需管理员。
- **淡入过渡**：shell 自身的行为，默认关闭，需向 `Progman` 发送 `0x052C` 开启
  （见 `core.enable_desktop_fade()`）。该状态保存在 explorer 内，重启或 explorer 重启后失效，
  因此程序启动时以及**每次切换桌面壁纸前**都会补发一次。
- **锁屏壁纸**：调用 WinRT `LockScreen.SetImageFileAsync`（通过 PowerShell），无需管理员。
- 两者完全独立，各自维护随机序列（一轮内不重复），各自的计时器互不重置。
- 不发起任何网络请求，只读取本地图片。

### 图库更新（gallery_update.py）

- 从 [sekai-master-db-diff](https://github.com/Sekai-World/sekai-master-db-diff) 拉取卡面数据。
- 支持按角色（中文名 / 罗马音 / 数字 id）、组合、稀有度筛选。
- FIFO 驱逐最旧图片，保持 pjsk 目录不超过设置的上限（默认 20 张，改动在下次更新时生效）。
- 触发方式：界面「立即更新」，或勾选「启用间隔更新」后由后台计时器按间隔触发。
- 所有定时均为程序内定时：程序未运行时不会更新。

### 手动添加图片

- 界面中选择或拖入本地图片；图片自动按主屏分辨率等比填充裁剪，存入 `library/custom/`。
- `custom/` 中的图片不受 FIFO 驱逐限制，永久保留。

## 本地安全边界

- 服务仅绑定 `127.0.0.1`，不开放局域网/公网，无登录系统。
- 写接口校验 `Host` / `Origin` 并要求同源令牌（自定义请求头），阻断跨站表单与不可信 CORS。
- 图库以服务端受控 ID 映射到已知目录，阻断 `../`、符号链接越界与任意文件读取。
- 上传限制体积（64 MiB）、数量（20 个/次）与类型，并用 Pillow 校验真实性。
- 不提供任意路径访问、shell 命令执行或用户指定程序启动。
- 端口被占用时不会误连其它服务：启动器会先用 `/api/identity` 校验实例身份。

## 技术细节

- 图片统一按屏幕分辨率（首次运行自动检测，可在 `config.json` 的 `screen` 手动指定）
  等比填充裁剪，PNG 编码保存。
- 图库网格使用后端生成的缩略图（缓存于 `cache/thumbs/`）并懒加载，避免一次拉全量原图。
- 配置存储在 `config.json`，首次运行自动生成默认值；旧配置缺失键会自动补齐（向后兼容）。
- 界面资源全部本地打包，离线可用，无外部 CDN／第三方字体。

## 日志与排查

- 图库更新日志：`logs/update.log`（界面「查看日志」可直接阅读）。
- 后台状态与错误也会显示在界面顶部状态栏与对应卡片。
- **界面状态自愈**：页面每 3 秒同步一次后端状态；「下一张」后直接用同一次响应的状态刷新
  界面，不等轮询；窗口重新可见/获得焦点时立即同步；请求带超时保护；
  若长时间同步不成功，顶部会显示「状态未同步，请点刷新」而不是静默停在旧数据。
  （窗口被最小化或长时间被遮挡时，浏览器会节流甚至冻结页面，属浏览器行为。）
- **UI 实机自检**（需 Node + Chrome）：
  ```
  chrome --headless=new --remote-debugging-port=9222 --user-data-dir=%TEMP%\pjsk-cdp about:blank
  node tools/ui_check.js http://127.0.0.1:8788/
  ```
  会检查：预览图能否加载、点「下一张」后界面是否立即刷新、外部状态变化后页面能否自行追上、
  页面冻结恢复后能否重新同步、以及有无未捕获的 JS 异常。

## 卸载

1. 从托盘菜单「退出」关闭程序。
2. 直接删除安装目录。
3. 如开启了开机自启，在启动项中删除 `pjsk-wallpaper`；
   快捷方式可在桌面和开始菜单中手动删除。
